# Jetlink 繁體、簡體與多國語言檢查

同一份分支隨系統語言切換，沒有拆成繁體／簡體兩個版本。

## 修改

- Jetlink 設定、連線狀態、模型來源、載入／建置進度、提示及大模型切換警示使用英文來源字串；69 個項目已補齊繁體與簡體翻譯。
- tici 行車徽章、側欄與兩種裝置的警示在顯示時翻譯。mici 的模式選項只翻譯顯示文字，參數索引仍為 off／usb／ios。
- 設定頁標題、描述、按鈕及更新結果使用動態翻譯，避免語言切換後仍保留初始化時的中文。外部模型資訊快取最多每秒更新一次。
- dragonpilot 原本只讀取 .mo，但分支並未自動產生 .mo。現在與主介面統一直接讀取 .po，不會因舊版或缺少 .mo 而忽略翻譯。
- 翻譯更新腳本改用主分支現有 Python 工具，不要求裝置安裝 xgettext／msgmerge／msgfmt。
- 修正主介面繁體／簡體 .po：宣告 nplurals=1 卻含 msgstr[1]，原本會造成 msgfmt 致命錯誤。保留 msgstr[0]，移除多餘的第二種形式。
- 修正 potools 合併時的語言識別及複數數量，避免更新後重新產生不符合語言規則的檔案。
- 其他語言保留既有翻譯；新增 Jetlink 項目若尚未翻譯，顯示英文來源文字。外部 App 回報的原始診斷／模型名稱保留原文。

## 實際檢查結果

- 25 份 .po 全部通過 msgfmt --check --check-format 編譯並可由 GNUTranslations 讀入。
- 部分既有檔頭仍會提示缺少翻譯者、修訂日期等資訊，屬非致命 metadata 警告，不影響編譯。
- 新增 69 個項目的繁體／簡體皆非空白，格式化參數一致。
- 實際 PO 載入器與編譯後 MO 的繁體／簡體結果逐項一致。
- 實際翻譯更新函式在暫存目錄重建 12 個可選語言，全部可編譯，繁體／簡體 Jetlink 翻譯保留。
- 繁體 → 簡體 → 英文 → 繁體切換、英文回退、複數規則及模板擷取通過。
- 四種 OpFont 字重的字元表都包含本次繁體／簡體翻譯使用的非 ASCII 字元。
- 7 項翻譯測試及既有 7 項 Jetlink 移植測試通過；Python 語法檢查通過。

可在有 GNU msgfmt 的開發環境重跑：

```sh
python3 tools/jetlink/test_translations.py
python3 tools/jetlink/test_port.py
```

這些是離線檢查，不等於 tici／mici 實機畫面、排版、USB 或行車測試。此包維持上一版 Jetlink 核心及控制演算法。
